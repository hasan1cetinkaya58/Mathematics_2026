# Determinants – Exercise 4

## Exercise 4. Triangular Matrix

Given:

$$A=\begin{pmatrix}2&4&1\\0&-3&5\\0&0&7\end{pmatrix}$$

This is an upper triangular matrix.

### Step 1: Apply the triangular matrix property.

The determinant of a triangular matrix is the product of its main
diagonal entries.

$$\det(A)=2\cdot(-3)\cdot7=-6\cdot7$$ $$\boxed{\det(A)=-42}$$

**General Rule:** For any upper or lower triangular matrix,

$$\boxed{\det(A)=a_{11}a_{22}\cdots a_{nn}}$$
