# Determinants – Exercise 6

## Exercise 6. Parameter and Invertibility

Given:

$$A(t)=\begin{pmatrix}t&1\\2&t\end{pmatrix}$$

We need to find all values of t for which the matrix is not invertible.

### Step 1: Calculate the determinant.

$$\det(A(t))=t\cdot t-1\cdot2=t^2-2$$

### Step 2: Set the determinant equal to zero.

$$t^2-2=0$$ $$t^2=2$$

### Step 3: Solve for t.

$$\boxed{t=\sqrt{2}\quad\text{or}\quad t=-\sqrt{2}}$$

A matrix is not invertible when its determinant is zero. Therefore,
these are the required values.
