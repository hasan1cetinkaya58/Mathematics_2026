The matrix sizes are:

A: 2 × 3 B: 3 × 4 C: 4 × 2 D: 2 × 2

A product XY is defined when the number of columns of X equals the number of rows of Y.

AB: Defined, result size 2 × 4.
BA: Not defined (4 ≠ 2).
BC: Defined, result size 3 × 2.
CB: Not defined (2 ≠ 3).
AC: Not defined (3 ≠ 4).
CA: Defined, result size 4 × 3.
AD: Not defined (3 ≠ 2).
DA: Defined, result size 2 × 3.
Explanation: Matrix multiplication requires compatible dimensions. The inner dimensions must be equal, and the result has the outer dimensions. Matrix multiplication is possible when the inner dimensions are equal. The result has the outer dimensions
