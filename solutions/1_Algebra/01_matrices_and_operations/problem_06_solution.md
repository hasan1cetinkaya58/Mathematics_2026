Given:

A = [[1, 2, 3], [4, 5, 6]]

B = [[1, 0], [2, 1], [-1, 3]]

1. Calculate Aᵀ

Aᵀ = [[1, 4], [2, 5], [3, 6]]

2. Calculate Bᵀ

Bᵀ = [[1, 2, -1], [0, 1, 3]]

3. Calculate AB

AB = [[1×1+2×2+3×(-1), 1×0+2×1+3×3], [4×1+5×2+6×(-1), 4×0+5×1+6×3]]

AB = [[2, 11], [8, 23]]

4. Verify the transpose property

(AB)ᵀ = [[2, 8], [11, 23]]

BᵀAᵀ = [[2, 8], [11, 23]]

Therefore:

(AB)ᵀ = BᵀAᵀ

Explanation: The transpose of a product reverses the order of the factors. This is an important property of matrix multiplication.
