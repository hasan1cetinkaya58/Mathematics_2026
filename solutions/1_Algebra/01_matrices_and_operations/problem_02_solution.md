Given:

A = [[1, 2], [-1, 3]]

B = [[4, -2], [0, 5]]

1. Addition

A + B = [[1+4, 2-2], [-1+0, 3+5]]

A + B = [[5, 0], [-1, 8]]

2. Subtraction

A - B = [[1-4, 2-(-2)], [-1-0, 3-5]]

A - B = [[-3, 4], [-1, -2]]

3. Scalar multiplication

3A = [[3, 6], [-3, 9]]

2B = [[8, -4], [0, 10]]

3A - 2B = [[3-8, 6-(-4)], [-3-0, 9-10]]

3A - 2B = [[-5, 10], [-3, -1]]

Explanation: Matrix addition and subtraction are possible only when both matrices have the same dimensions because corresponding entries must be combined.
