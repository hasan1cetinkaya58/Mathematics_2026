Formula for a Matrix Power
Given:

A = [[1, 1], [0, 1]]

Calculate A²:
A² = A × A

A² = [[1, 2], [0, 1]]

Calculate A³:
A³ = A² × A

A³ = [[1, 3], [0, 1]]

Calculate A⁴:
A⁴ = A³ × A

A⁴ = [[1, 4], [0, 1]]

Calculate A⁵:
A⁵ = A⁴ × A

A⁵ = [[1, 5], [0, 1]]

General formula:
Aⁿ = [[1, n], [0, 1]]

Verification:
Assume:

Aⁿ = [[1, n], [0, 1]]

Then:

Aⁿ⁺¹ = Aⁿ × A

Aⁿ⁺¹ = [[1, n], [0, 1]] × [[1, 1], [0, 1]]

Aⁿ⁺¹ = [[1, n + 1], [0, 1]]

Therefore, the formula is true for the next power as well.

Explanation:

Each multiplication increases the upper-right entry by one. This creates a simple pattern that can be generalized for any positive integer n.
