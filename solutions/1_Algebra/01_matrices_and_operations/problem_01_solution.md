Exercise 1. Matrix Size and Entries
Given:

A = [[2, -1, 3], [0, 4, 5]]

B = [[1, 0], [-2, 3], [4, 1]]

The size of matrix A is 2 × 3.
The size of matrix B is 3 × 2.
The requested entries are:

a12 = -1
a23 = 3
b21 = -2
b32 = 1
The second row of A is:

[0, 4, 5]

The first column of B is:

[1, -2, 4]ᵀ

Explanation: A matrix size is determined by its number of rows and columns. The first index represents the row, and the second index represents the column.
