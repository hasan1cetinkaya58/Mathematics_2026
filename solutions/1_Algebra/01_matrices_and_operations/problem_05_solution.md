Exercise 5. Matrix Times Vector
Given:

A = [[2, -1], [1, 3]]

x = [4, 2]ᵀ

Calculate Ax:

Ax = [[2×4 + (-1)×2], [1×4 + 3×2]]

Ax = [6, 10]ᵀ

The columns of A are:

c1 = [2, 1]ᵀ

c2 = [-1, 3]ᵀ

Expressing Ax as a linear combination:

Ax = 4c1 + 2c2

Ax = 4[2, 1]ᵀ + 2[-1, 3]ᵀ

Ax = [8, 4]ᵀ + [-2, 6]ᵀ

Ax = [6, 10]ᵀ

Explanation: Multiplying a matrix by a vector is equivalent to taking a linear combination of the columns of the matrix, using the vector entries as coefficients.
